ОБНОВЛЁННАЯ ВЕРСИЯ ИГР

Добавлены визуальные схемы/картинки к заданиям и более ясные инструкции. Исправлены несколько нелогичных вариантов ответа.
Имена HTML-файлов сохранены, поэтому существующие исправленные QR-коды продолжают вести на те же страницы.

Чтобы опубликовать:
1) распакуй архив;
2) загрузи HTML-файлы в корень репозитория GitHub и подтверди замену старых;
3) не переименовывай файлы и не удаляй страницы со случайными именами;
4) дождись завершения GitHub Pages и проверь несколько QR-кодов.

Важно: это встроенные в страницы SVG-иллюстрации, интернет для их показа не нужен.
